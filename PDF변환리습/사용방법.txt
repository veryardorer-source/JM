JM 여러 도면 PDF 일괄 변환 리습
================================

파일
  JM_BatchPDF.lsp

현재 DWG 안의 여러 도면을 선택 출력 (추천)
  1. AutoCAD 명령창에 APPLOAD를 입력하고 JM_BatchPDF.lsp를 로드합니다.
  2. 모델(Model) 탭에서 JM_SELPDF를 입력합니다.
  3. PDF 저장 폴더, 파일명 앞부분, 용지 크기를 지정합니다.
  4. 첫 번째 도면을 감싸는 범위의 두 모서리를 차례로 클릭합니다.
  5. 다음 도면도 같은 방법으로 두 모서리를 클릭합니다.
  6. 필요한 도면 범위를 모두 지정한 뒤 '첫 번째 모서리' 질문에서 Enter를 누릅니다.
  7. 지정한 순서대로 이름_01.pdf, 이름_02.pdf처럼 생성됩니다.

  주의: 도면 객체를 드래그하여 선택하는 방식이 아닙니다. 각 도면을 출력할
        사각 범위의 대각선 방향 두 점을 클릭하는 방식입니다.

  예: 5개 도면의 외곽선을 선택하고 이름을 '평면도'로 입력
      평면도_01.pdf ~ 평면도_05.pdf

여러 DWG 파일을 폴더 단위로 출력
  1. AutoCAD 명령창에 APPLOAD를 입력합니다.
  2. JM_BatchPDF.lsp 파일을 선택해 로드합니다.
  3. 명령창에 JM_BATCHPDF를 입력합니다.
  4. DWG 파일들이 들어 있는 폴더를 선택합니다.
  5. PDF를 저장할 폴더를 선택합니다.
  6. 출력 대상을 선택합니다.
     - Model  : 각 도면의 모델 공간만 출력
     - Layout : 각 도면의 배치(Layout)만 출력 (기본값)
     - All    : 모델 공간과 모든 배치를 출력

PDF 파일명
  - 출력 대상이 하나면: 도면명.pdf
  - 한 도면에서 여러 배치를 출력하면: 도면명_배치명.pdf
  - 같은 파일명이 이미 있으면 _1, _2처럼 번호를 붙여 기존 파일을 보호합니다.

출력 기준
  - 프린터: DWG To PDF.pc3
  - 모델 공간: 도면 범위(Extents), 용지에 맞춤, 가운데 정렬
  - 배치 공간: 배치(Layout) 영역, 1:1
  - 원본 DWG는 읽기 전용으로 열며 변경 내용을 저장하지 않습니다.

주의 사항
  - 배치의 용지 크기, 방향, 플롯 스타일은 각 DWG에 저장된 페이지 설정을 사용합니다.
  - AutoCAD에 "DWG To PDF.pc3" 프린터가 있어야 합니다.
  - 변환 중인 도면에 외부참조/폰트 누락 경고가 있으면 결과를 확인해 주세요.
  - 실패한 파일 수는 완료 창과 명령창에 표시됩니다.

자동 로드(선택)
  APPLOAD의 시작하기 세트(Startup Suite)에 JM_BatchPDF.lsp를 추가하면
  AutoCAD 실행 때마다 자동으로 로드됩니다.
