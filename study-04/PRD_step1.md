# PRD Step 1 — 냉장고 이미지 인식

## 개요
사용자가 냉장고 사진을 업로드하면, `google/gemma-4-31b-it:free` 모델이 이미지를 분석하여 식재료 목록을 추출한다.

---

## 목표
- 냉장고 사진 → 식재료 목록 자동 추출
- 결과를 Step 2(레시피 생성)에서 바로 사용할 수 있는 구조로 전달

---

## 기술 스택
| 항목 | 선택 |
|------|------|
| 프레임워크 | React 18 + Vite |
| 스타일 | Tailwind CSS |
| AI API | OpenRouter (`google/gemma-4-31b-it:free`) |
| 이미지 전달 | base64 인코딩 (data URI) |

---

## 기능 요구사항

### 1. 이미지 업로드 UI
- 드래그&드롭 또는 파일 선택 버튼으로 이미지 업로드
- 지원 형식: JPG, PNG, WEBP
- 업로드 후 미리보기 이미지 표시
- 최대 파일 크기: 10MB (초과 시 안내 메시지)

### 2. 이미지 → base64 변환
- 브라우저 `FileReader` API로 base64 변환
- API 전송 전 이미지를 최대 1024px로 리사이즈 (Canvas API 사용)
  - 이유: free 모델의 rate limit / 토큰 절약

### 3. OpenRouter API 호출
- 엔드포인트: `https://openrouter.ai/api/v1/chat/completions`
- 모델: `google/gemma-4-31b-it:free`
- 프롬프트 전략:
  ```
  이 냉장고 사진에서 보이는 식재료를 모두 찾아주세요.
  반드시 아래 JSON 형식으로만 답하세요. 다른 설명은 하지 마세요.
  {"ingredients": ["재료1", "재료2", ...]}
  ```
- 응답에서 JSON 파싱 (정규식 fallback 포함)

### 4. 결과 표시
- 인식된 재료를 태그(chip) 형태로 나열
- 각 태그에 삭제(X) 버튼 — 사용자가 오인식된 재료 제거 가능
- 재료 직접 추가 입력창 제공
- "레시피 추천받기" 버튼 → Step 2로 재료 목록 전달

---

## 상태 흐름
```
초기 상태
  → 이미지 선택
  → 미리보기 표시
  → [분석하기] 버튼 클릭
  → 로딩 스피너 (API 호출 중)
  → 재료 태그 목록 표시
  → [레시피 추천받기] 클릭 → Step 2
```

---

## 에러 처리
| 상황 | 처리 |
|------|------|
| 파일 크기 초과 | "10MB 이하 이미지를 사용해주세요" 토스트 |
| API 429 (rate limit) | "잠시 후 다시 시도해주세요" + 15초 자동 재시도 1회 |
| API 기타 오류 | "분석에 실패했습니다. 다시 시도해주세요" |
| 재료 0개 인식 | "식재료를 찾지 못했어요. 사진을 확인해주세요" |

## API 요청/응답 예시

**요청**
```json
{
  "model": "google/gemma-4-31b-it:free",
  "messages": [
    {
      "role": "user",
      "content": [
        { "type": "text", "text": "이 냉장고 사진에서 보이는 식재료를 모두 찾아주세요. 반드시 JSON 형식으로만 답하세요: {\"ingredients\": [\"재료1\", ...]}" },
        { "type": "image_url", "image_url": { "url": "data:image/jpeg;base64,..." } }
      ]
    }
  ]
}
```

**응답 파싱 결과**
```json
{ "ingredients": ["달걀", "우유", "당근", "양파", "두부", "김치"] }
```
