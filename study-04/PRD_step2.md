# PRD Step 2 — 레시피 생성

## 개요
Step 1에서 추출한 식재료 목록을 바탕으로 `google/gemma-4-31b-it:free` 모델이 실용적인 레시피를 생성한다.
사용자는 필터 옵션으로 결과를 조정하고, 마음에 드는 레시피를 Step 3 프로필에 저장할 수 있다.

---

## 목표
- 재료 → 레시피 복수 추천 (기본 3개)
- 조리 시간·난이도·식단 타입 필터 지원
- 레시피를 구조화된 데이터로 저장 가능한 형태로 생성

---

## 기술 스택
| 항목 | 선택 |
|------|------|
| 프레임워크 | React 18 + Vite (Step 1과 동일 앱) |
| AI API | OpenRouter (`google/gemma-4-31b-it:free`) |
| 상태관리 | React useState / Context |
| 데이터 전달 | Step 1 → Step 2: props 또는 전역 상태 |

---

## 기능 요구사항

### 1. 입력 — 재료 확인 패널
- Step 1에서 넘어온 재료 목록 표시 (읽기 전용 태그)
- "재료 수정" 버튼 클릭 시 Step 1으로 이동

### 2. 필터 옵션 (선택사항)
| 필터 | 옵션 |
|------|------|
| 조리 시간 | 15분 이하 / 30분 이하 / 제한 없음 |
| 난이도 | 쉬움 / 보통 / 어려움 |
| 식단 타입 | 일반 / 채식 / 저칼로리 |
| 인원 수 | 1인 / 2인 / 4인 |

### 3. OpenRouter API 호출
- 모델: `google/gemma-4-31b-it:free`
- 프롬프트 전략:
  ```
  다음 재료로 만들 수 있는 레시피 3가지를 추천해주세요.
  재료: {ingredients}
  조건: {filters}

  반드시 아래 JSON 형식으로만 답하세요:
  {
    "recipes": [
      {
        "name": "요리 이름",
        "time": "조리 시간(분)",
        "difficulty": "쉬움|보통|어려움",
        "servings": 인원수,
        "ingredients_needed": ["필요재료1", ...],
        "steps": ["1. 단계", "2. 단계", ...],
        "tip": "요리 팁 (선택)"
      }
    ]
  }
  ```
- 응답 JSON 파싱 (마크다운 코드블록 제거 포함)

### 4. 레시피 카드 표시
각 레시피를 카드 형태로 표시:
- 요리 이름 (대제목)
- 조리 시간 / 난이도 / 인원 수 (아이콘 + 텍스트)
- 필요 재료 목록 (현재 보유 재료는 강조 표시)
- 조리 순서 (번호 리스트)
- 요리 팁 (있을 경우)
- [저장하기] 버튼 → Step 3 프로필에 저장

### 5. 재추천 기능
- [다른 레시피 추천받기] 버튼 → 동일 재료로 새 레시피 3개 재요청
- 이전 추천과 중복되지 않도록 프롬프트에 제외 목록 포함

---

## 상태 흐름
```
Step 1에서 재료 전달
  → 재료 확인 + 필터 설정
  → [레시피 생성] 버튼 클릭
  → 로딩 상태 (스켈레톤 카드 3개 표시)
  → 레시피 카드 3개 표시
  → [저장하기] → Step 3 저장 / [다른 레시피] → 재호출
```

---

## 에러 처리
| 상황 | 처리 |
|------|------|
| API 429 | "잠시 후 다시 시도해주세요" + 30초 자동 재시도 1회 |
| JSON 파싱 실패 | 원문 텍스트로 fallback 표시 |
| 레시피 0개 | "재료로 만들 수 있는 레시피를 찾지 못했어요" |
| 재료 1개 이하 | 생성 버튼 비활성화 + 안내 문구 |

## API 요청/응답 예시

**요청 body**
```json
{
  "model": "google/gemma-4-31b-it:free",
  "messages": [
    {
      "role": "user",
      "content": "다음 재료로 만들 수 있는 레시피 3가지를 추천해주세요.\n재료: 달걀, 우유, 당근, 양파\n조건: 30분 이하, 쉬움, 2인분\n반드시 JSON 형식으로만 답하세요: {\"recipes\": [...]}"
    }
  ]
}
```

**파싱된 레시피 구조**

```json
      "time": "15",
      "difficulty": "쉬움",
      "servings": 2,
      "ingredients_needed": ["달걀 2개", "당근 1/2개", "소금", "식용유"],
      "steps": [
        "1. 당근을 채 썬다.",
        "2. 팬에 기름을 두르고 당근을 볶는다.",
        "3. 달걀을 풀어 넣고 함께 볶는다.",
        "4. 소금으로 간한다."
      ],
      "tip": "달걀은 반숙 상태에서 불을 끄면 더 부드럽습니다."
    }
  ]
}
```
