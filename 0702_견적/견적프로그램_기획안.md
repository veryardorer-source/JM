# JM 견적프로그램 기획안

> 작성일: 2026-07-02 · 작성: 대표 + Claude
> 목표: **계약 전 상세견적서 작성 시간을 하루 → 1시간 이내로 단축**
> 형태: JM OS(jm-system, Next.js + Supabase) 내 "견적" 모듈로 개발, https://jm-interior.vercel.app 에 함께 배포

---

## 1. 배경 · 문제

- 인테리어 의뢰 고객은 **계약 전에 상세 견적서**를 원한다. 디자인이 확정되기 전 단계라 상세견적을 내기 어렵고, 낼 때마다 시간이 오래 걸린다.
- 현재 수작업 흐름: 도면 치수 확인 → 물량산출 엑셀에 입력 → 산출된 수량을 견적서 내역서에 **손으로 옮겨 적기** → 갑지 요율 계산 → 표지 작성.
- 이 중 "옮겨 적기" 이후가 전부 기계적인 작업 → **자동화 대상**.

- 평당가(VAT 포함) 중앙값: 전체 163만 / 뷰티·미용 227만 / 식음료 160만 / 상업 150만 / 사무실 147만 / 학원·교습소 138만

- 실적 이익률: 중앙값 36%, 공종별 실지출/견적 — 소방 131%(견적 상향 필요) · 냉난방 97% · 목작업 66% · 가설/설비 43~45%

## 3. 사용자 · 권한

| 역할(JM OS role) | 견적 모듈 권한 |
|---|---|
| `admin` (대표) | 견적 생성·수정·삭제, 단가표 관리, 요율 변경, 손익 통계 열람 |

## 4. 기능 구조 — 3단계

### 4.1 개략견적 (상담 단계, 1분)
- 입력: **업종 + 평수** (+ 마감등급: 기본/표준/고급)
- 출력: "○○ 업종 ○평 → 예상 ○,○○○만 ~ ○,○○○만원 (VAT 포함)"
- 근거: 업종별 평당가 통계(중앙값 ± 범위) × 등급 계수. 유사 현장 3건 자동 표시(면적·업종 가까운 순).
- 용도: 첫 상담 전화·미팅에서 즉답. 고객용 한 장짜리 PDF 출력.

### 4.2 상세견적 (계약 전, 목표 1시간)
- **① 현장 정보**: 현장명, 고객, 업종, 면적, 층고, 각재 규격 선택(2400/2700/3000/3600×28×28)
- **② 구역(방) 치수 입력**: 구역 추가 → 벽별 길이·높이 입력 (물량산출 엑셀의 웹 버전)
- **③ 공종 선택**: 가설/철거/목작업/전기/조명/소방/도장/필름/도배/수장/타일/데코타일/가구/금속/설비/냉난방… 체크
- **④ 자동 물량산출** (5장 계산 규칙): 자재 수량 자동 계산 → 자재단가표에서 단가 적용
- **⑤ 노무비 자동 제안**: 공종별 평당 품 통계 × 면적 → 인원 제안 (수정 가능)
- **⑥ 내역 편집**: 자동 생성된 내역서를 행 단위로 수정/추가/삭제
- **⑦ 갑지 자동 계산**: 요율 적용(고용·산재·일반관리·이윤·네고·단수정리·VAT)
- **⑧ 출력**: 기존 양식 그대로 **엑셀(.xlsx) 다운로드** (표지/갑지/공종별집계표/내역서 4시트) + PDF

### 4.3 손익 피드백 (공사 후)
- 견적 ↔ JM OS `projects` 연결 → 공사 완료 후 실지출 입력(또는 기존 `project_costs` 연동)
- 공종별 실지출/견적 비율 자동 누적 → **단가·품 통계가 스스로 정교해지는 구조**
- 견적 화면에 경고 표시: "소방은 최근 실적에서 견적 초과(131%) — 단가 확인"

## 5. 물량산출 계산 규칙 (확정)

| 자재 | 공식 | 비고 |
|---|---|---|
| 각재 | 세로 = 벽길이÷450 + 1 (개) · 가로 = (벽길이÷각재길이)×2 (개) | 규격 현장별 선택: 2400/2700/3000×28×28(한 단 20개), 3600×28×28(한 단 12개) |
| 석고보드 | 벽면적 ÷ 1.62㎡ → 올림 (장) | 900×1800. 도배면 |
| MDF | 면적 ÷ 2.88㎡ (장) | 1220×2440. 필름·도장·좁은면·기둥·모서리 |
| 합판(보강) | 길이÷450 올림 ÷ 13 (장) | 벽두께 80mm 기준(1220÷80≈13) |
| 걸레받이·천장몰딩 | 길이 ÷ 2400 → 올림 (본) | |
| 벽지 | 석고면적 × 0.3025 ÷ 5 → 올림 (롤) | ㎡→평 환산, 1롤=5평. 천장 별도 산출 |
| 필름 | 가로 × 높이 (㎡) | 1000 간격 × 높이 |
| **타일** | 면적 ÷ 1.44㎡ → 올림 (박스) | 600각 기준. **데코타일과 별도 항목** |
| **데코타일** | 면적 ÷ 3.24㎡ → 올림 (박스) | 450각 16장/박스, 600각 9장/박스 |
| **조명** | 종류별 수량·길이 직접 입력 | 3인치/스팟/T5/T7/펜던트/벽등 등 → 전기작업 내역으로 연결 |

## 6. 데이터 모델 (Supabase 신규 테이블)

```
estimates            견적 헤더 (현장명, 고객, 업종, 면적, 상태, project_id FK→projects, 요율 스냅샷, 네고)
estimate_rooms       구역 치수 (estimate_id, 구역명, 벽별 길이/높이 JSON)
estimate_sections    공종 (estimate_id, 공종명, 정렬순서)
estimate_items       내역 행 (section_id, 품명, 규격, 단위, 수량, 재료비단가, 노무비단가, 경비단가, 자동생성 여부)
price_book           자재 단가표 (품명, 규격, 단위, 단가, 공종, 유효일) — 자재단가.xlsx 이관
labor_stats          공종별 원단위 (평당 품, 평당 금액, 실지출/견적 비율) — 통계 리포트 이관, 손익 입력 시 갱신
estimate_versions    (선택) 수정 이력 — 추가견적서 대응
```

- 권한: admin/designer만 접근(field 차단). 금전 데이터이므로 JM OS 기존 정책과 동일하게 적용.

## 7. 화면 목록

1. **견적 목록** — 상태(작성중/제출/계약/완료), 검색, 복제(유사 현장 복사 후 수정 = 가장 빠른 실무 패턴)
2. **개략견적 계산기** — 업종+평수 입력 → 범위 즉시 표시 (목록 상단 위젯)
3. **견적 작성 마법사** — 4.2의 ①~⑧ 단계형 화면 (저장은 단계마다 자동)
4. **물량산출 시트** — 구역별 치수 표 입력(엑셀 느낌의 그리드), 자재별 수량 실시간 표시
5. **내역서 편집** — 공종 접기/펼치기, 행 추가, 소계·직접비 실시간 합산
6. **단가표 관리** (admin) — price_book CRUD, 엑셀 업로드로 일괄 갱신
7. **통계 대시보드** — 평당가 추이, 공종별 원단위, 견적 대비 실적

## 8. 엑셀 출력 사양

- 기존 견적서와 **동일한 4시트 구성**: 표지 / 갑지 / 공종별집계표 / 내역서
- 갑지: 직접공사비(재료비/노무비/경비) → 고용·산재·일반관리·이윤 → 단수정리(천단위 절사) → 네고 → 총공사비 → VAT → 합계, 한글 금액 표기("일금 ○○○원정")
- 내역서: 공종별 블록 + [소계], 항목번호·품명·규격·단위·수량·재료비/노무비/경비 단가·금액
- 구현: 서버에서 xlsx 생성(exceljs) — 회사 서식(로고·괘선) 템플릿 파일에 값만 채움

## 9. 개발 로드맵

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| **M1 (MVP)** | 견적 CRUD + 내역서 편집 + 갑지 자동계산 + 엑셀 출력 + 단가표 | 기존 견적서 1건을 프로그램으로 재현해 실제 고객에게 제출 |
| **M2** | 물량산출(구역 치수 → 자재 수량 자동) + 노무비 제안 + 개략견적 계산기 | 신규 현장 1건을 치수 입력만으로 견적 완성 |
| **M3** | 손익 입력·피드백 + 통계 대시보드 + 유사현장 추천 + 견적 버전(추가견적) | 공사 완료 현장의 실지출 입력 → 통계 자동 갱신 확인 |

- M1부터 실사용 가능. 각 단계는 독립 배포.
- 기존 데이터 이관: 견적서 90건 파싱 스크립트(이미 작성됨, 성공률 100%)로 과거 견적을 DB에 넣어 "복제해서 시작"과 통계의 기반으로 활용.

## 10. 리스크 · 결정 필요 사항

- **P_2_견적프로그램(구버전)**: 물량산출 웹앱 빌드본만 있고 소스가 없음 → 참고만 하고 새로 개발.
- **jm-system 통합 vs 별도 앱**: 본 기획은 jm-system 모듈 기준. 견적은 admin/designer 전용이라 기존 권한 체계로 충분.
- **자재단가 관리 주체**: 단가 변동 시 누가 갱신할지(대표 승인制 권장).
- **고객 제공 형태**: 엑셀 → PDF 변환까지 자동화할지, 엑셀만 출력 후 수동 PDF로 할지 (M1은 엑셀만).
